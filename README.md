# DRAFT ROOM V0.6 — Read the Player

## 실행

`index.html` 또는 별도 `DRAFT-ROOM-V0.6.html`을 다운로드하여 브라우저에서 여세요. 서버·설치·인터넷 연결이 필요하지 않습니다. 모바일에서는 파일 미리보기 앱이 아닌 JavaScript 실행이 가능한 브라우저에서 열어야 합니다.

V0.5와 능력치·성장 모델이 달라 저장 파일은 호환되지 않습니다. V0.5 파일과 저장 공간을 덮어쓰지 않습니다. V0.6 저장 키는 `draft-room-kbo-v6-scouting`, JSON 포맷은 `draft-room-v06`, 버전은 6입니다.

## 주요 변경

- 공개 능력치를 20–80, 5단위로 표시. 내부는 세밀한 연속 값으로 계산합니다.
- 현재 기량 / 미래 가치(FV) / 플로어 / 실링 구분. 미래 전망은 확정 결과가 아닙니다.
- 투수: 구위·커맨드·변화구·체력. 야수: 컨택·장타력·주력·수비, 보조 선구안.
- 서로 다른 툴 성장과 조기·일반·늦은 성장곡선. 드물게 낮은 완성도의 장기 프로젝트 후보가 생성됩니다.
- 기존 1군 보직 유지, 연차별 출전량 확대, 건강·부진·경쟁에 근거한 역할 설명.
- 선발 승수·이닝과 야수 홈런 산식 개편. 선발 등판·퀄리티스타트 기록과 승수 정렬 추가.
- 시즌 시작 → 종료 공개 평가와 세부 툴 경력 기록. 5년 후 젊은 육성형의 판단 유보 표시.
- 최대어급 전망의 희소성 개선. 지명된 라운드 때문에 선수 잠재력이 바뀌지는 않습니다.
- 언론 예상 뒤 팀장 추천 단계: 주 추천 1명 + 대안 2명, 성향·근거·우려 표시.
- 팀장 성향과 매 게임 달라지는 세부 보강 목표. AI·추천은 공개 정보만 사용합니다.
- 즉전감 / 플로어 / 실링 중복 태그 및 필터.
- 해외 마이너·독립 복귀, 드문 짧은 MLB 경험 복귀. 이지에서만 선호 구단 공개.
- 가상 소속 28개 추가, 총 160개. 국내 프로 리그는 기존 10개 구단 유지.

## 유지 기능

전국 7라운드, 선택적 지역 1차, 대학 얼리와 국내 대졸 의무 1명, 2027–2031년 총 5시즌, 전 구단 기록실, 동기 내 개인상, 간소화 리그·포스트시즌, 자동 1대1 트레이드·제한적 방출, 입단 인터뷰·뉴스·팬심·첫해 약속 평가, JSON 저장·복원, 첫해 결과 PNG.

후보 200명: 고졸 136 / 국내 대졸 30 / 대학 얼리 16 / 국내 독립 6 / 해외 대학 4 / 마이너·MLB 복귀 6 / 해외 독립 복귀 2. 지역별 고졸 17명. MLB 경험자는 매 게임 존재하지 않으며, 드물게 마이너 복귀 한 자리를 대체합니다.

## 범위와 주의

선수·학교·해외 구단·성적·전력은 게임용 가상 데이터입니다. 공식 KBO 규정이나 실제 선수 평가를 재현하지 않습니다. 해외 복귀는 국내 프로 미입단자의 첫 국내 도전이라는 가상 지원 규칙이며 실제 유예·계약·지원 자격을 재현하지 않습니다. 개인상은 드래프트 동기 내 수상이며 전체 리그 MVP가 아닙니다.

계약금 협상, 지명 거부, 진학 후 재지명, 연례 새 드래프트, 전체 기존 선수단, 이도류, 수동 트레이드·재계약은 포함하지 않았습니다. 팀별 기존 보강 포지션 3개는 유지하고 세부 유형과 팀장 성향을 랜덤화합니다.

## 개발과 검증

Node.js 24 및 Python 3 환경에서:

```bash
npm ci
npm run build
npm test
npm run test:balance
CHROMIUM_BIN=/usr/bin/chromium npm run test:browser
```

실행용 HTML 자체에는 Node/Python/Chromium 설치가 필요하지 않습니다. 위 명령은 개발·자동 검증용입니다.

`src/`는 편집 가능한 소스, `build.py`는 단일 HTML 빌더입니다. `tests/v06*`에 현재 버전 테스트와 결과를 포함했습니다. 파일 무결성은 `build-manifest.json`의 SHA-256으로 확인할 수 있습니다.

- `grades06.js`: 20–80 정의·툴 생성·관측.
- `scouting06.js`: 공개 정보 기반 추천·성향·세부 수요.
- `season.js`: 역할·기록·성장.
- `career.js`: 5년 경력·이동·누적·평가.
- `engine.js`: 진행·의무지명·결정적 저장 복원.
- `view06.js`, `v06.css`: 신규 추천·발전 UI. 기존 이름의 view04/view05 파일도 현 버전 표시 계층의 일부입니다.

`examples/demo-v06-five-seasons.json`은 브라우저 검증에 사용한 LG·지역 ON·노말의 5년 완료 진행 파일입니다. 게임의 ‘진행 불러오기’에서 선택하면 결과와 기록실을 바로 둘러볼 수 있습니다.

테스트 결과의 범위와 남은 검증은 `QA.md`를 참고하세요.
