# DRAFT ROOM v0.4 — In the Spotlight

난이도, 언론의 예상, 지명 뉴스와 커뮤니티, 기록 정렬, 단장 인터뷰와 팬심을 추가한 **Spotlight / 전국 5라운드판**입니다.

## 실행

ZIP을 풀고 `index.html`을 최신 브라우저에서 여십시오. 서버·인터넷·로그인·API 키가 필요하지 않습니다. 편집용 소스도 포함하지만 실행에는 HTML 한 파일이면 충분합니다.

- 기본: **노말 / 지역 1차 OFF**.
- OFF: 전국 5라운드, 구단당 5명. ON: 지역 1명 + 전국 5라운드, 구단당 6명.
- 구단·난이도 선택 → 언론 모의 드래프트 → 실제 지명과 현장 반응 → 단장·신인 인터뷰 → 2027 루키 시즌 → 구단주 평가.
- 후보는 기존과 같은 200명: 고졸 160 / 대졸 30 / 독립 6 / 해외 4입니다.
- 이 패키지는 `kbo-draft-v0.4-spotlight/`의 검증된 구현본입니다. 라운드 확장이나 계약 협상은 넣지 않았습니다.

## 1. 난이도

선수 능력, 관측 오차, 성장·부상·출전 확률은 난이도로 바꾸지 않습니다. 모든 난이도에서 같은 공개 기록과 스카우트 추정치를 볼 수 있습니다.

- **이지:** 상세 조언과 공개 평가 기반 비교 후보 두 명을 제공합니다. AI는 공개 종합평가 중심이며 판단 변동이 큽니다.
- **노말:** 기존 수준의 준비도·보강·후보 수·중복 지명 조언을 제공합니다. AI가 보강 필요와 육성 성향을 균형 있게 고려합니다.
- **하드:** 강점·과제 등 핵심 관찰만 제공합니다. AI는 기존 지명과 같은 포지션의 중복, 보강 필요, 공개 상위 후보군 내 희소성을 더 따집니다.

AI는 `rules04.js`의 명시적인 공개 정보 목록으로 만든 선수 정보만 받습니다. 숨은 준비도·성장 한계·컨디션 위험·미래 성적은 받지 않습니다. 하드가 모든 시드에서 더 높은 점수를 얻거나 사람에게 항상 더 어렵다는 보장은 없습니다.

## 2. 시작 전 언론 모의 드래프트

가상 매체 **다이아몬드 데일리**는 준비도와 당장의 보강, **퓨처 베이스볼**은 성장 기대와 장기 활용을 중시합니다. 각 매체가 전국 1라운드 10개 구단을 예측합니다.

지역 1차 ON이면 지역 1차 예측도 별도로 만듭니다. **전국 1라운드 예상은 각 매체가 예측한 지역 1차 결과를 전제로 합니다.** 매체 내부에서 같은 선수를 두 번 예측하지 않으며 지역 자격을 지킵니다. 실제 지역 지명이 달라도 과거 예측을 고치지 않습니다.

모의 드래프트는 첫 실제 지명 전에 고정합니다. 새로고침·난이도 변경 비교·나중의 재열람으로 같은 시드의 예측을 다시 뽑지 않습니다. 게임 중 ‘언론 예상’에서 실제 선택과 비교할 수 있습니다. 2~5라운드 예측은 이번 범위 밖입니다.

## 3. 지역 1차와 전국 1라운드 뉴스

두 단계는 다른 이벤트입니다. 전 구단의 해당 지명마다 기사와 댓글 세 개를 만듭니다. OFF는 10건, ON은 20건입니다. 우리 팀 지명 직후에는 기존 감독·선수 인터뷰와 함께 보여주며, 다른 구단의 반응도 ‘뉴스룸’에서 볼 수 있습니다.

- 매체 예측 일치 여부, 선택 시점에 남은 후보의 공개 순위, 보강 필요, 중복 포지션, 선수 경로와 지역 맥락을 사용합니다.
- 보강·육성·신중론의 서로 다른 시선을 함께 보여줍니다. 무조건적인 찬사나 욕설로 구성하지 않습니다.
- 뉴스는 **그 지명 이전의 기록만** 참고합니다. 후속 지명·시즌 성적 때문에 과거 기사가 바뀌지 않습니다.
- 기사·댓글은 실제 보도나 실제 팬 여론이 아닌 게임용 창작입니다.

## 4. 스탯·능력별 정렬

22개 항목을 오름차순·내림차순으로 정렬할 수 있습니다.

- 종합: 스카우트 순위, 우리 팀 적합도.
- 능력 추정: 준비도, 성장 기대, 장타력, 제구, 주력, 수비.
- 타격: 홈런, 타율, 타점, OPS, 도루, 안타, 타석.
- 투구: 최고 구속, ERA, 이닝, 탈삼진, 허용 볼넷, 승리.
- 공통: 경기 수.

선택한 정렬값을 선수 행에 직접 표시합니다. 해당하지 않는 기록은 `—`이며 **양방향 모두 마지막**입니다. 0은 정상 기록으로 취급합니다. 투수의 타격 기록이나 야수의 구속을 임의로 끼워 넣지 않습니다. 이닝은 표시 문자열이 아니라 아웃 수로 비교합니다(10.2는 10⅔이닝). 동률은 공개 순위·선수 ID로 안정적으로 정렬합니다.

검색·포지션·출신·평판·관심 필터와 함께 사용할 수 있습니다. 서로 다른 리그의 타율·ERA, 적은 표본의 기록을 단순 비교하지 않도록 안내합니다. 능력 추정치는 숨은 실제 준비도나 성장 한계의 정답표가 아닙니다.

## 5. 단장 인터뷰와 팬심

드래프트 종료 후 세 가지 답변 중 **한 번만** 선택합니다. 확정 후에는 바꿀 수 없습니다.

1. **1군 경쟁:** 첫해 1군 경험 2명 이상을 약속합니다.
2. **육성 과정:** 신인 60% 이상이 계획 이행 70점 이상을 달성하도록 약속합니다. 1군 미데뷔여도 이행할 수 있습니다.
3. **보강과 활용:** 우선 보강 3개 포지션을 확보하고, 그 자리의 신인 2명 이상이 계획 이행 70점 이상을 달성하도록 약속합니다.

답변 선택 전에 기준, 공개 지명 구성에 따른 반응, 예상 팬심 변화를 보여줍니다. 인터뷰 선택은 선수 능력이나 성장·출전 확률을 조작하지 않습니다.

### 팬심과 구단주 평가는 다릅니다

팬심은 50에서 시작하는 0~100의 게임용 지수입니다. 실제 여론 조사 비율이 아닙니다. 우리 팀의 지역 1차/전국 1라운드 뉴스, 단장 인터뷰, 시즌 후 약속 평가를 순서대로 반영합니다. 버튼을 눌러 변동 내역을 볼 수 있습니다. 이벤트에서 매번 계산하므로 재열람·새로고침으로 중복 가산되지 않습니다.

구단주 기본 평가 **보강 40% / 첫해 계획 이행 25% / 미래 가치·성장 35%**는 유지합니다. 여기에 약속 이행에 따른 최대 **±4점**만 별도로 더합니다. 팬심 점수 자체는 더하지 않습니다.

- 1군 경쟁: 경험 2명 이상 +4 / 1명 0 / 0명 −4.
- 육성 과정: 목표 인원 이상 +3 / 목표보다 1명 적음 0 / 그 외 −3.
- 보강과 활용: 보강 3개와 이행 2명 이상 +4 / 보강 2개 이상과 이행 1명 이상 0 / 그 외 −3.

퓨처스 육성 자체를 실패로 취급하지 않습니다. 1군 경험을 직접 약속한 경우에만 그 약속의 이행 여부를 별도로 판단합니다.

## 저장과 재현성

- 저장 키는 **`draft-room-kbo-v4-spotlight`**, 저장 형식은 version 4입니다.
- v0.3/v0.3.1의 저장 키를 읽거나 지우지 않습니다. 이전 저장은 자동 이전하지 않습니다.
- 브라우저·파일 경로·아티팩트가 다르면 저장 공간도 다를 수 있습니다. 다운로드한 HTML로 기존 진행이 자동 복사된다는 뜻은 아닙니다.
- 시드, 지명, 고정 예측, 뉴스, 인터뷰 답변과 시즌 결과를 검증한 뒤 복원합니다. 조작되거나 손상된 저장은 이어받지 않습니다.
- 물리적인 선수 생성과 시즌 난수 모델은 v0.3 계열을 유지했습니다. 같은 선수·시드·소속 구단이면 난이도나 인터뷰 답변 때문에 선수 성적이 재추첨되지 않습니다. AI 지명 선택은 난이도별로 다를 수 있습니다.

## 유지한 배경 설정과 한계

v0.3.1의 학교명 수정안을 유지했습니다. 전체 132개 소속(고교 87, 고교 연령 BC 16, 국내 대학 16, 독립구단 4, 해외 대학 9)과 지역·야구 프로그램 평판은 같습니다. 명문 장산고와 약소 장산자동차고는 별개 소속이며, 미국 롱아일랜드하버대를 포함합니다.

기준일 2026-09-16, 입단·신인 시즌 2027년을 유지합니다. 생일·만 나이·출생지·출신 고교·현재 소속·학업/활동 이력·지원 자격은 구분합니다. 지역 1차는 현재 고졸 지원자만 허용하며 고교 연령 BC를 포함하는 게임용 단순화 규칙입니다. 대학·독립·해외파는 출생지나 과거 학교로 지역 자격을 얻지 않습니다.

이름은 40개 성씨와 363개 완성형 이름의 편집 목록이며 2000~2007년 출생 이름 순위 통계를 확보해 사용한 것이 아닙니다. 학교 평판은 학업 수준이나 실제 기관의 우열을 뜻하지 않습니다. 학교명 조회 자료는 `audit/`에 있으며 검색 미확인이 실존 기관의 부재를 보장하지 않습니다. 구단 이름은 아직 실제 프로구단 이름을 사용합니다. 선수·기록·전력·대회 경력은 가상입니다.

계약 협상·지명 거부·해외 마이너리거 세부 경력·이도류·희귀 유학생·프로구단 가명화·라운드 확장은 이번에 추가하지 않았습니다.

## 개발과 검증

런타임은 외부 의존성이 없으며 아래 의존성은 개발 테스트에만 필요합니다.

```bash
npm install
npm run build
npm test
npm run test:browser
npm run test:balance
```

브라우저 검사는 Chromium이 필요합니다. `CHROMIUM_BIN`으로 실행 파일을 지정할 수 있습니다. 카탈로그를 다시 생성할 때는 `npm run build:catalog` 다음 `npm run build`를 실행합니다. `audit/`의 공개 웹 조회 스크립트는 제작 시 감사용이며 게임 실행에는 필요하지 않습니다.

- `src/rules04.js`: 공개 정보 목록, 난이도별 AI, 정렬 비교 함수.
- `src/press.js`: 고정 예측, 기사·댓글, 인터뷰 약속과 평가 규칙.
- `src/view04.js`, `src/v04.css`: 새 화면 구성.
- `src/engine.js`: 단계·선택·저장 검증·팬심과 평가 연결.
- `src/data.js`, `src/season.js`: 기존 선수 생성 및 첫해 육성 모델.
- `tests/`: 자동 테스트, 원본 물리 데이터 해시, 브라우저/균형 실험과 로그.
- `QA.md`: 이 배포본에서 실제 실행한 검증 결과.
- `build-manifest.json`: 배포 HTML·소스 지문 및 검증 지표.
