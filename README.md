# DRAFT ROOM V0.5 — Five Years Later

**한 번의 드래프트, 다섯 시즌의 이야기.**

전국 7라운드로 지명한 선수들이 2027~2031년 어떻게 성장하는지, 다른 구단의 선택과 함께 확인하는 오프라인 가상 KBO 드래프트 게임입니다.

## 실행

ZIP을 풀고 **`index.html`을 최신 브라우저에서 여세요.** 인터넷·서버·로그인·API 키가 필요 없습니다. 별도로 제공된 단일 HTML 파일도 같은 게임입니다.

1. 구단·난이도·지역 1차 ON/OFF 선택.
2. 언론 모의 지명 확인 후 드래프트 시작.
3. 전국 7라운드 지명, 국내 대학 졸업예정자 최소 1명 확보.
4. 단장 인터뷰 답변 확정 → 첫 시즌 진행.
5. 연도별 기록·수상·소식을 확인하며 총 5시즌 진행.
6. 전체 구단 기록실과 최종 평가에서 다른 팀의 선택과 비교.

모바일은 선수 프로필이 후보 목록 아래에 나타납니다. 기록 표는 좌우로 스크롤할 수 있으며, 선수 이름을 누르면 상세 경력이 열립니다.

## V0.5 추가 기능

### 7라운드 / 대학 얼리 / 의무지명

- 지역 OFF: 전국 7명 × 10개 구단 = 70명.
- 지역 ON: 지역 1명 + 전국 7명 = 구단당 8명, 전체 80명.
- 후보 200명: 고졸 144 / 국내 대학 졸업예정 30 / 대학 2학년 얼리 16 / 독립구단 6 / 해외 대학 4.
- 고졸은 기존 8개 지역에 각각 18명씩 생성합니다.
- 국내 대학 졸업예정자 1명 이상 의무지명. **얼리·독립·해외 대학은 의무 대상에서 제외**하는 단순화 규칙입니다.
- 대학 얼리는 재학 학년·만 나이·이력·인터뷰를 구분합니다.
- 의무 미충족 상태에서 마지막 전국 지명권에 도달하면 대상 선수만 표시됩니다. 사람과 CPU에 같은 규칙을 적용합니다.
- 이미 의무를 채운 구단이 다른 구단에 꼭 필요한 마지막 대학 후보를 소진할 수 없도록 보호합니다.

### 상위 지명자 첫해 기회 확대

지역 1차·전국 1~3라운드에 제한적인 시험 콜업 기회 보정을 적용합니다. 보정은 첫해 중심이며 2년 차에 축소되고 3년 차부터 사라집니다. 기량·적응·건강·보강 필요가 함께 작동하며, 상위 지명이라고 안착하거나 좋은 성적을 보장하지 않습니다.

모든 난이도·CPU·사람에게 동일한 물리 모델을 사용합니다. 난이도는 기존처럼 조언과 지명 AI의 판단에만 영향을 줍니다.

### 총 5시즌 경력

- 2027년부터 2031년까지 정확히 5시즌.
- 전 구단의 이번 지명 선수 전체를 같은 엔진으로 처리합니다.
- 기량 발전·정체·건강 상태·보직이 다음 해에 이어집니다.
- 선수의 지명 전 프로필은 고정하고, 해마다 공개 기량 추정과 경력 상태를 별도로 관리합니다.
- 연간 및 누적 1군·퓨처스 기록을 조회합니다.
- 누적 AVG·OPS·ERA는 원시 기록 합계로 재계산합니다. 이닝의 .1/.2는 1/3·2/3이닝입니다.
- 과거 조회·정렬·새로고침으로 성적이 재추첨되지 않습니다.
- 매년 새 드래프트를 하는 구단 운영 모드는 아닙니다.

### 개인상·팀 우승

- 개인상: **이번 드래프트 동기 중 올해의 타자·투수**. 리그 전체 MVP·골든글러브가 아닙니다.
- 최소 60타석 / 20이닝 기준. 후보가 없으면 해당 상은 수여하지 않습니다. 동률은 선수 ID로 안정적으로 처리합니다.
- 타자 선정 지수: 타석 × 0.055 + (OPS − 0.65) × 50 + 홈런 × 0.7.
- 투수 선정 지수: 아웃 수 × 0.12 + (5.5 − ERA) × 6 + 탈삼진 × 0.05.
- 팀 성적: 기존 배경 전력 + 지명 선수 기여 + 시즌 변동성의 간소화 모델.
- 팀당 144경기, 팀 간 16경기, 무승부 없음. 리그 합계 720승·720패.
- 포스트시즌: 4위가 1승을 갖고 시작하는 2승제 와일드카드, 준PO·PO 3승제, 한국시리즈 4승제의 게임용 규칙.
- 해당 시즌 우승 구단 소속으로 1군 경기에 출전한 동기 선수에게 우승 경력을 기록합니다.

### 방출·자동 트레이드

- 첫해 종료에는 선수 이동이 없습니다. 2·3·4년 차 종료 후만 판정합니다.
- 마지막 해 이후 추가 비시즌은 진행하지 않습니다.
- 방출은 공개 기량 추정·1군 기회 부족·나이·구단 자원 수를 함께 고려합니다. 첫해 미데뷔만으로 방출하지 않습니다.
- 현재 소속 동기 자원이 4명 이하인 팀에서는 추가 방출하지 않습니다.
- 트레이드는 이번 지명 선수 사이의 1대1 자동 교환이며, 비시즌마다 최대 한 건입니다. 양 구단 포지션 수요와 공개 평가 가치 차이를 검토합니다.
- 숨은 실제 기량·성장 한계로 트레이드 상대를 고르지 않습니다.
- 원지명 구단, 기록 당시 구단, 현재 소속을 분리합니다. 이적 후에도 과거 수상 소속은 바뀌지 않습니다.
- 방출 이후 기존 기록은 보존하지만 추가 프로 성적은 없습니다. 재계약·독립리그 경력은 아직 없습니다.

### 전체 구단 기록실·평가

- 드래프트 중에도 전 구단의 현재까지 지명을 조회합니다.
- 구단, 원지명/현재 소속 기준, 연도/누적, 1군/퓨처스 필터.
- 지명 순서, 경기, 홈런, OPS, ERA, 이닝, 기여 지수, 수상 수 정렬.
- 선택한 리그 기준으로 기록을 정렬하며, 기여 지수는 1군 전용입니다.
- 선수 상세: 신체·투타·학력·아마추어 기록·공개 추정치·연간/누적 기록·수상·이적 이력.
- 첫해 단장 약속과 팬심은 1년 차 결과로 한 번만 고정합니다.
- 다년 평가: 보강 포지션 20% + 인원·시즌 수로 정규화한 1군 기여 50% + 공개 기량 추정 발전 30%.
- 기여 항목은 `총 기여 / (원지명 인원 × 완료 시즌 수 × 20) × 100`, 0~100으로 제한합니다.
- 발전 항목은 `공개 기량 추정 변화 평균 × 3.5 + 35`, 0~100으로 제한합니다.
- A 85점 이상 / B 70점 이상 / C 55점 이상 / D 그 미만. 이 지수는 WAR나 실제 선수 가치가 아닙니다.
- 원지명 선수의 전 구단 기여와 우리 팀에서 낸 기여를 분리합니다. 트레이드 영입자는 원지명 성공으로 계산하지 않습니다.

## 유지한 V0.4 기능

팀 선택과 보강 정보, 지역 1차, 난이도, 가상 선수·학교 배경, 공개 스카우트 정보 기반 AI, 두 매체의 모의 지명, 지역 1차·전국 1라운드 뉴스·커뮤니티·감독/선수 인터뷰, 지명 후 신인·단장 인터뷰, 팬심, 22개 스카우팅 보드 정렬, 첫해 구단주 평가·결과 이미지 저장을 유지했습니다.

## 저장·복원

- 새 저장 키: `draft-room-kbo-v5-five-years`, 저장 형식 version 5.
- V0.4 저장과 호환되지 않으며 V0.4 키를 읽거나 지우지 않습니다.
- 자동 저장은 같은 브라우저·파일 경로의 저장 공간에 의존합니다.
- **진행 파일 저장**으로 JSON을 내보내고, **진행 불러오기**로 다른 브라우저/경로에서 복원할 수 있습니다.
- 불러오기는 지명 적법성·뉴스·시즌·이적·수상 결과를 재현 검증한 뒤 사용자 확인을 받아 현재 진행을 대체합니다.
- 편집·손상된 진행 파일은 거부합니다. 2MB보다 큰 파일은 불러오지 않습니다.
- `examples/demo-five-seasons.json`은 기록실을 바로 둘러볼 수 있는 5시즌 완료 예시입니다. 자신의 진행을 먼저 내보낸 뒤 불러오세요.
- 오프라인 클라이언트 게임이므로 개발자 도구나 저장 JSON을 통한 내부 상태 열람 자체를 막는 보안 장치는 아닙니다.

## 범위와 한계

선수·학교·전력·기록·수상·기사·댓글은 가상입니다. 실제 구단 이름만 사용합니다. 특정 연도 공식 KBO 규정 전체, 실제 선수단의 경기별 개인 기록, 실제 수상 투표는 재현하지 않습니다.

계약 협상, 지명 거부·재지원, 이도류, 마이너리거 세부 경력, 20–80 평가체계, 스카우트 팀장 성향·추천, 세부 보강 수요 랜덤화, 수동 트레이드 협상, FA·연봉·재계약은 이번 범위 밖입니다.

## 개발

```bash
npm ci
npm run build
npm test
npm run test:balance
CHROMIUM_BIN=/path/to/chromium npm run test:browser
```

Node.js 20 이상과 Python 3을 권장합니다. Chromium은 실제 브라우저 테스트에만 필요합니다. 게임 실행에는 개발 의존성이 없습니다.

- `src/engine.js`: 드래프트, 의무지명, 상태 전이, 저장 재현 검증.
- `src/data.js`, `src/biography.js`: 후보·학력·얼리 생성.
- `src/season.js`: 단일 연도 성장·기회·기록 모델.
- `src/career.js`: 5년 경력, 리그·수상·비시즌, 누적·평가.
- `src/view05.js`, `src/v05.css`: 기록실·선수 경력·시즌·다년 평가 화면.
- `src/app.js`: 기존 드래프트 UI와 새 화면·저장 기능 연결.
- `src/rules04.js`, `src/press.js`, `src/view04.js`: 기존 공개 AI·언론·팬심 기반 유지. 파일명의 04는 기반 모듈 구분입니다.
- `tests/v05*`: V0.5 전용 코어·UI·밸런스·브라우저 검사와 실제 실행 로그.
- `QA.md`: 검증 범위와 결과.
- `build-manifest.json`: 배포 파일 SHA-256 지문.
